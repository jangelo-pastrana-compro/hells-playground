HELL'S PLAYGROUND (Firebase accounts + multiplayer)
1) Firebase console > Build > Authentication > Get started > Email/Password > Enable > Save.
2) Realtime Database > Rules > paste database.rules.json > Publish.
3) Open index.html (or upload folder to app.netlify.com/drop and share the link).
Accounts: email + username + password. Progress/history/saves sync to your account.
Multiplayer: START > MULTIPLAYER > CREATE ROOM / JOIN ROOM.
